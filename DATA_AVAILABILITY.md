# Data availability statement template

Replace this template with the repository URL and archival identifier only after depositing genuine data.

Raw, unprocessed reflectance spectra; sample and sensor metadata; blank measurements; calibration standards; interference measurements; stability measurements; analysis configuration; and trained-model evaluation outputs are provided with the reproducibility repository. Synthetic demonstration data are separately identified and are not used as experimental evidence. Any restricted clinical data must be described with a lawful access procedure and an independently accessible metadata record.

The manuscript must not simultaneously claim analysis of 10,000 spectra and state that no datasets were generated or analyzed.
